# 学习积分工作台 v2.0

给孩子用的学习积分 + 神兽养成工作台。单文件应用，手机和电脑都能用，数据可自动同步。

## 快速开始

直接用浏览器打开 `index.html` 即可使用，所有数据自动保存在本机浏览器里。

## 手机上使用（推荐）

1. 把这个文件夹上传到 GitHub 仓库（`index.html` 放根目录）。
2. 仓库 → Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/root`，保存。
3. 等 1 分钟，访问 `https://你的用户名.github.io/仓库名/`。
4. 手机浏览器打开该网址 → 分享/菜单 → **添加到主屏幕**，即可像 App 一样全屏使用，断网也能打开。

## 手机与电脑数据同步

同步用一份免费的 GitHub Gist 当云端仓库，双向合并，两台设备互不覆盖。

1. 在电脑上打开应用 → 右上角 ☁️ → 按提示生成一个 GitHub Token（只勾选 `gist` 权限）→ 测试 → 创建云同步。
2. 在手机上打开同一个网址 → ☁️ → 把电脑页面上那串 **配对码** 粘贴进去 → 连接。
3. 之后两边都会自动同步：操作后 1 秒上传，前台每 25 秒拉取一次，切回 App 时也会自动拉取。

> 配对码里包含你的 Token，只发给家人，不要发到群里。任何一台设备都可以在 ☁️ → 断开。

不想用云同步也行：设置 → 导出备份 / 导入备份，手动搬家。

## 主要功能

- **积分页**：今日概览（净增、获得、消费、连续打卡、目标进度环）、快速记账、今日流水、历史流水、成就徽章。
- **神兽页**：神兽形象与阶段（蛋→幼兽→少年兽→成年兽→顶级形态）、心情与喂食、属性面板（攻击/防御/速度、出处、栖息地、专属技能、喜好与厌恶）、神兽图鉴、皮肤、积分消费。
- **快捷操作**：记账后可一键撤销；删除可撤销；`Ctrl/Cmd + Z` 撤销上一步。
- **设置**：姓名、每日目标分、导出/导入、清空数据。

## 自定义

- **改规则**：积分页 → 快速记账 → 规则右上角 ✏️ 编辑；或 ＋ 新规则。
- **改每日目标**：右上角 ⚙️ → 每日目标。
- **换神兽图片**：把图片放进 `assets/beasts/`，命名见该目录下的 README。
- **改神兽资料**：`index.html` 里的 `BEASTS` 数组（名字、出处、属性数值、喜好、最爱食物）。

## 数据说明

数据存在浏览器 `localStorage` 的 `learningPointsWorkstation` 键中，包含积分流水、规则、神兽、结算记录。
换设备或清浏览器数据前，请先导出备份。
