# 用真实/精美图片替换矢量神兽

页面默认使用内置的矢量插画。只要把图片放进这个目录，页面会自动优先使用图片，
**不需要改任何代码**，刷新即可看到效果。

## 命名规则

| 文件名 | 用途 |
| --- | --- |
| `qilin.png` | 麒麟（所有阶段都用这张） |
| `qilin-adult.png` | 麒麟的「成年兽」阶段专用（优先级高于 `qilin.png`） |

支持的阶段后缀：`egg`（蛋）、`young`（幼兽）、`teen`（少年兽）、`adult`（成年兽）、`top`（顶级形态）。

五种神兽文件名前缀：

- `qilin` 麒麟
- `baize` 白泽
- `pixiu` 貔貅
- `kunpeng` 鲲鹏
- `jiuwei` 九尾狐

## 建议规格

- 格式：PNG（透明背景最佳）
- 尺寸：正方 1024×1024，或横版 1200×1000
- 主体居中、留出约 8% 边距，底部留一点空间给"地面"
- 深色背景下的插画效果最好（页面是深色主题）

## 提示词方向（用任意 AI 绘图工具生成）

> 中国神话神兽 **麒麟**，写实插画风格，金色鳞片与柔顺鬃毛，鹿角，
> 站姿侧身，柔和体积光与轮廓光，深色透明背景，细节丰富，游戏原画质感，
> 主体居中，无文字，无水印

把上面方括号里的名字换成白泽 / 貔貅 / 鲲鹏 / 九尾狐即可。
